⚖️ Operational Security Thresholds

🟢 SAFE CORRIDOR (Risk < 35%)

Automated clearance granted. Customer is permitted to continue directly to PayPal Sandbox checkout.

🟡 SUSPICIOUS CORRIDOR (35% ≤ Risk < 70%)

Checkout held. Requires secondary step-up authentication (SMS/OTP) or manual security review before release.

🔴 HIGH-RISK CORRIDOR (Risk ≥ 70%)

Severe fraud probability. Processing is strictly blocked. Account session is flagged to prevent unauthorized withdrawals.
