DEFENSE-IN-DEPTH ARCHITECTURE

How ScamShield Pay Works

A multi-tiered security pipeline designed to stop scams before checkout clearance.

01

Signal Extraction

Extracts multi-dimensional features: monetary value, temporal velocity, hardware fingerprints, and routing geography.

02

Random Forest Inference

Evaluates non-linear feature interactions across 200 decision trees to produce an empirical probability score.

03

Auditable Policy Review

Combines ML probabilities with explainable heuristics: Safe (<35%), Suspicious (35-70% MFA hold), or High-Risk (≥70% block).

04

PayPal Settlement Guard

Orders v2 REST API only issues orders for approved transactions, with strict idempotent capture and amount validation.

CORE CAPABILITIES

Intelligent Payment Protection Features

Built from the ground up for modern fintech applications and payment providers.

🤖

Ensemble Machine Learning

Trained Random Forest Classifier with stratified splitting prevents data leakage and delivers consistent non-linear fraud scoring across complex transaction scenarios.

🔍

Explainable AI (XAI)

Clearly distinguishes empirical model probabilities from human-readable behavioral heuristics, giving compliance teams transparent operational visibility into every decision.

🔐

Step-Up MFA Challenge

Suspicious transactions trigger a server-controlled 6-digit OTP verification challenge with timing-safe SHA-256 hashing, attempt limits, and 10-minute expiration.

💳

PayPal Orders v2 Integration

Zero-trust backend gating creates PayPal orders strictly after server clearance, tying reference IDs and amounts with deterministic idempotency keys.

📜

Persistent SQLite Audit Ledger

Every evaluated payment is permanently archived in SQLite via Flask-SQLAlchemy with complete timestamps, risk scores, status transitions, and capture IDs.

📊

Fintech Operations Dashboard

Real-time admin console featuring Chart.js visualizers, KPI summary metrics, transaction audit filters, and CSV export capabilities for fraud analysts.

Verified Payment Gateway

PayPal Sandbox Integration Architecture

ScamShield Pay operates as an authoritative security proxy in front of PayPal. The frontend JavaScript SDK never initiates orders directly; instead, orders are generated server-side using OAuth 2.0 bearer authentication only after verifying database clearance. Idempotency headers (PayPal-Request-Id) prevent duplicate charges.
